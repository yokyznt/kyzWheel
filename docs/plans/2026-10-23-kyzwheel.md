# kyzWheel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rueda radial glass para Windows que se abre con atajo o con arrastrar+Shift, con secciones configurables (WhatsApp, Correo, Convertidor y más).

**Architecture:** Lógica pura y testeable en `KyzWheel.Core`; Win32 (hooks, hotkeys, credenciales, autostart) en `KyzWheel.Platform`; conversión en `KyzWheel.Convert`; correo en `KyzWheel.Mail`; UI WinUI 3 en `KyzWheel.App`; `KyzWheel.Guard` (NativeAOT) mantiene viva la app; WhatsApp en un sidecar Node (`sidecar/whatsapp`) por JSON-lines sobre stdio.

**Tech Stack:** .NET 10, WinUI 3 / Windows App SDK 1.8 (unpackaged, self-contained), WinUIEx, H.NotifyIcon.WinUI, CommunityToolkit.Mvvm, Magick.NET-Q8-AnyCPU, DocumentFormat.OpenXml, MailKit, Microsoft.Web.WebView2, PDFsharp, PDFtoImage, Microsoft.ML.OnnxRuntime, Velopack, xUnit; Node 24 + baileys + node:test.

**Spec:** `docs/specs/2026-10-23-kyzwheel-design.md`

## Global Constraints

- Código sin comentarios (ni `//`, ni XML docs, ni comentarios XAML/CSS).
- Windows 10 2004+ / 11 x64 únicamente; `net10.0-windows10.0.19041.0`, `WindowsAppSDKSelfContained=true`, `WindowsPackageType=None`.
- Config en `%APPDATA%\kyzWheel\config.json`; datos/caché en `%LOCALAPPDATA%\kyzWheel\`.
- Nunca sobrescribir archivos del usuario; salida junto al original con sufijo `_1`, `_2`…
- Convertidor sin red; Mail/WhatsApp solo a sus servidores; sin telemetría.
- Secretos solo en Credential Manager (target `kyzWheel:mail:<email>`).
- Slots: mínimo 1, máximo 8.
- Atajo por defecto `Ctrl+Shift+Space`.
- Animaciones con Composition API y tiempos del spec; respetar `UISettings.AnimationsEnabled`.
- Metas: reposo < 70 MB, atajo→visible < 60 ms, hooks < 1 ms.
- Cada fase en su rama (`feat/v1-...`), commit por tarea, push + `gh pr create --base main --body-file`. El merge lo hace el usuario. No commitear `.impeccable/hook.cache.json`.

## Review Focus

1. Varios archivos arrastrados juntos → convertir todos, una notificación con el total (test en Task 13).
2. Rutas largas (>260), Unicode y archivos de OneDrive solo-nube → convierte o avisa claro, nunca crash (test en Task 4 y Task 11).
3. Monitores con DPI distintos → la rueda aparece centrada en el cursor y dentro del área de trabajo del monitor donde está el cursor (test en Task 3 `ClampToWorkArea`).
4. Sin internet o contraseña revocada → la sección Correo muestra estado «Sin conexión»/«Revisa la contraseña» por cuenta y las demás cuentas siguen (test en Task 16).
5. Arrastre desde una ventana elevada (admin) o con Shift ya presionado antes del arrastre → no abre la rueda por error, no se cuelga (test en Task 6).
